## Stated purpose

Make the silent-delivery-failure class of bug observable — when an agent's
reply makes it into the session transcript but never reaches the external
channel (e.g. stale channel context after a model fallback), operators
should learn about it via stderr, and internal callers should see it via
the function's return value.

## In scope (after slim — 2026-05-08)

- `deliveryStatus` object on `deliverAgentCommandResult`'s **return value**
  with fields: `requested`, `attempted`, `succeeded`, `hadPartialFailure?`,
  `error?`. So internal callers (gateway send handler, agent dispatcher)
  can branch on it.
- Stderr warning `[delivery] delivery requested but not completed: <reason>`
  with reason chain: no channel / internal channel / no target / threw /
  zero results. Fires only when delivery requested + payloads non-empty +
  not succeeded + not in JSON mode.
- `try/catch` wrapping `deliverOutboundPayloads` so non-bestEffort throws
  don't escape uncaught; bestEffort errors → `error: true` in status.
- Status-tracking unit tests in `src/agents/command/delivery.test.ts`.
- CHANGELOG entry under `## Unreleased > Changes` (added 2026-05-08; required by CONTRIBUTING).

## NOT in scope (slimmed out — moved to #57755)

## Implementation notes / gotchas

- Upstream's `deliverAgentCommandResult` uses `mergeResultMetaOverrides`
  and `writeRuntimeJson` — preserve those calls verbatim during conflict
  resolution. The earlier rebase that bled JSON-side surface in here
  happened because I copied the old PR's full structure including its
  `runtime.log(JSON.stringify(...))` pattern instead of upstream's
  `writeRuntimeJson(runtime, ...)`. **Pattern:** when resolving conflicts
  on upstream-refactored helpers, preserve upstream's helper call sites;
  only add/remove the parts your PR is intended to change.
- Tests removed during slim (now belong to #57755): "returns
  deliveryStatus on early return when deliver=true but no payloads",
  "includes deliveryStatus in JSON output when deliver=true", "omits
  deliveryStatus from JSON output when deliver=false".
